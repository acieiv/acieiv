## How I Think About Data

I use **“context systems”** to describe tools that collect, organize, analyze,
and explain information around a real question.

**The questions:** What changed? Why does it matter? What evidence supports
the decision?

AI can help with that process, but **data quality, domain understanding, and
clear communication** remain central.
